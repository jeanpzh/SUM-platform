# Mesa de ingesta

Use case: ui-mockup. Create realistic production-quality UI design, a focused primary desktop dashboard screen for SUM, the proposed FISI / UNMSM academic assistant, for administrative staff ingesting official PDFs. Spanish UI. One horizontal image of ONE focused screen, 1440 x 1024, no device or browser frame, no collage, no alternate screen inside it.
Current date anchor: 2 October 2026, Lima. This is a proposed product, mock content; no real live operational metrics.
Repository grounding: DESIGN.md defines Ember Studio: warm #FAFAF9 canvas, #F5F5F4 surface, #E7E5E4 raised surface, #1C1917 primary text, #57534E secondary, #78716C metadata. Terracotta #C2410C only for actions/active states/progress; hover #9A3412, amber #F59E0B sparingly for attention, green #16A34A success, red #DC2626 failures. Playfair Display serif headings with tight tracking and Source Sans 3 UI, 14–16px readable baseline. No Inter/Arial/Roboto/Helvetica. Strong refined typographic contrast, restrained editorial luxury, generous whitespace and exact grid alignment. Ultra-light Phosphor style icons. A quiet warm sidebar 256px wide, SUM wordmark, FISI · UNMSM, active 'Documentos', secondary 'Trabajos', bottom 'Administración'. Role 'Administrador', no invented role permissions.
Premium direction from high-end-visual-design: tactile subtle nested outer rim on the main upload enclosure only, soft ambient depth, precise surfaces, no harsh shadows, no glass gradients, no thick icons, no pointless ornament. Content has 12px corners, inputs and buttons 8px matching DESIGN.md; slim warm tonal separators. One terracotta primary action per view; all secondary actions understated. Avoid card overload or identical KPI grids. Product imagery is a useful document-page thumbnail with small typeset resolution text, no decorative stock photography.
Architecture grounding from ARQUITECTURA.md and docs/separacion-servicios.md: staff register official document/version/applicability/relations. Upload enters a durable queue. Background indexer extracts text, chunks, embeds, validates, and publishes a COMPLETE version only. Upload does not equal publication. Show human-facing workflow 'En cola → Extracción → Indexación → Validación → Publicado'; technical backend services should not appear as UI jargon. A failed ingest leaves the previously published version available. No manual 'publish now' action invented; publish occurs after validation. Official-source provenance and document applicability matter. File size limits are unspecified so DO NOT invent MB caps. Avoid unsupported numeric total statistics.
Screen title 'Documentos institucionales', small eyebrow 'BASE DE CONOCIMIENTO', short supporting line 'Carga fuentes oficiales y sigue su procesamiento.' Relevant upload form: 'Origen oficial' URL, 'Versión o resolución', 'Aplicabilidad' selectable 'Por verificar'. Realistic filename 'Reglamento-Matricula-Pregrado-2026.pdf'. Helpful line 'Disponible para consultas después de validar e indexar.' Progress is separately identified as processing, not normative validity.
Responsive intention: desktop sidebar becomes accessible menu below 768px; all columns become a single full-width stack, 16px mobile side padding, primary file selection/upload first, source metadata next, jobs below; 44–48px touch targets and no dependence on drag-and-drop. At tablet the main panels stack. Do not place an extra mobile screen in this image. Clear hierarchy and generous purposeful whitespace. No chart, decorative blob, invented feature menu, fake analytics, or marketing section. Never warp or stretch UI. Do not use card wrappers for every row.

Layout strategy: upload-first asymmetrical workbench. Main content starts at x304 with editorial heading. A wide left upload area about 650px occupies the middle; slim right metadata column about 360px. Upload zone with a subtle nested double rim, lightly inset surface, a useful document thumbnail and 'Arrastra tus PDF aquí', secondary outline 'Seleccionar archivos' (tap alternative), small 'Solo archivos PDF'. Beneath zone a selected-file row. Metadata labels are above fields, source URL 'https://sum.unmsm.edu.pe', version 'RR / 2026', applicability 'Por verificar'. ONE primary CTA at bottom of metadata 'Iniciar ingesta' with subtle trailing circle arrow. Lower supporting area 'Trabajos recientes' is a clean grouped list/table of 3 rows, not cards: 'Reglamento de matrícula 2026' — 'Indexando · 62%' terracotta slim progress; 'Cronograma de pregrado 2026' — 'Publicado' green understated; 'Directiva de rectificación' — 'Error de extracción' red and ghost 'Reintentar'. Fine supporting note near errors 'La versión publicada anterior sigue disponible.' Rows have filename, status, small time text 'Hoy'. Composition open, cream editorial surfaces, no pointless statistics.

## Additional generation constraints

Registro de fuentes: Body, navigation, labels, inputs and buttons use Source Sans 3; only headings use Playfair Display. SUM wordmark only; no invented crest/seal.

Seguimiento de ingesta: Same font constraints; SUM wordmark in warm near-black; no crest/seal, no blue colors. Processing accents terracotta/stone and success green. Title on one line; no decorative gear or spinner.
